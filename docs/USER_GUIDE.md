# Мини-гайд по FlowTrack

Этот гайд помогает быстро начать работу с FlowTrack без технических настроек.

## 1. Вход и личный кабинет

1. Откройте [FlowTrack](https://flowtrack-personal.andrewkim2002.chatgpt.site).
2. Нажмите **«Войти или зарегистрироваться»**.
3. Войдите через свой аккаунт ChatGPT.
4. При первом входе личный кабинет создастся автоматически.

Создавать отдельный пароль FlowTrack не нужно. У каждого аккаунта ChatGPT свой
набор задач, проектов, заметок и других данных.

На компьютере профиль находится внизу бокового меню. На телефоне нажмите значок
пользователя в верхней панели. Выход выполняется только через пункт
**«Выйти из аккаунта»** внутри профиля.

## 2. Главная страница «Сегодня»

На главной странице собрана краткая картина дня:

- количество активных привычек;
- процент выполненных задач;
- активные проекты и цели;
- задачи на сегодня;
- непривязанные задачи во «Входящих»;
- динамика привычек за неделю;
- недавние заметки;
- текущий таймер или Помодоро.

Приветствие использует имя текущего пользователя и меняется по местному времени.

## 3. Быстрое добавление и поиск

### Быстрая задача

Нажмите **«Быстро добавить»** в боковом меню или плавающую кнопку `+` на
телефоне. Достаточно ввести название — задача попадёт во «Входящие», а детали
можно заполнить позже.

### Поиск

Глобальный поиск находит:

- задачи;
- проекты;
- привычки;
- заметки;
- цели.

### Горячие клавиши

| Комбинация | Действие |
| --- | --- |
| `Ctrl/⌘ + K` | Быстро добавить задачу |
| `Ctrl/⌘ + Shift + K` | Открыть глобальный поиск |
| `/` | Открыть поиск, если курсор не находится в поле ввода |
| `Esc` | Закрыть открытое окно |

## 4. Привычки

1. Откройте раздел **«Привычки»**.
2. Нажмите **«Новая привычка»**.
3. Укажите название, периодичность, цель в день, иконку и цвет.
4. Отмечайте выполнение в календаре.

Поддерживаются ежедневные привычки, действия по будням и еженедельные цели.
FlowTrack рассчитывает текущую серию выполнений.

## 5. Задачи и расписание

В задаче можно указать:

- дату и время;
- статус;
- приоритет;
- проект;
- повторение;
- оценку времени;
- теги;
- сохранение во «Входящих».

Задачу можно отметить выполненной прямо в списке. Повторяющиеся задачи
поддерживают режимы: ежедневно, по будням, еженедельно и ежемесячно.

В недельном календаре кнопка **«Задача»** внутри дня сразу создаёт запись с уже
выбранной датой.

## 6. Проекты и канбан

1. Создайте проект.
2. FlowTrack добавит базовые рабочие колонки.
3. При необходимости добавьте или переименуйте колонку.
4. Создайте карточки-задачи.
5. Перетаскивайте карточки за специальную ручку.
6. Перетаскивайте колонки за ручку в их заголовке.

Перенос задачи между колонками сохраняется в базе и автоматически меняет её
статус. Поэтому одна и та же задача корректно отображается и на доске, и в
расписании.

Если перетаскивание не начинается, удерживайте именно ручку и сместите курсор
или палец примерно на несколько пикселей — это защита от случайного клика.

## 7. Таймер и Помодоро

### Свободный таймер

Используйте его для обычного учёта времени:

1. Нажмите **«Запустить таймер»**.
2. Укажите занятие, проект и задачу.
3. Остановите таймер после завершения.

Отсчёт продолжается после перезагрузки страницы. Завершённые сессии попадают в
историю.

### Помодоро

В режиме Помодоро можно настроить:

- продолжительность фокуса;
- короткий перерыв;
- длинный перерыв;
- количество циклов до длинного перерыва;
- автоматический запуск перерывов;
- автоматический запуск следующего фокуса;
- проект и задачу.

Цикл можно поставить на паузу, продолжить, вручную перевести на следующий этап
или полностью завершить. Свободный таймер и Помодоро нельзя запускать
одновременно.

## 8. Заметки

Для заметки доступны:

- заголовок и теги;
- цвет карточки;
- закрепление;
- жирный, курсивный и зачёркнутый текст;
- подзаголовки;
- маркированные и нумерованные списки;
- списки задач;
- цитаты;
- блоки кода;
- ссылки;
- отмена и повтор редактирования.

Поиск в разделе заметок проверяет заголовок, текст и теги.

## 9. Цели

У цели можно указать категорию, дедлайн, текущее значение, целевое значение,
единицу измерения и цвет.

Поддерживаются крупные финансовые значения до `1 000 000 000 000`. Когда
текущее значение достигает целевого, цель автоматически получает статус
завершённой.

## 10. Удаление и восстановление

Задачи, проекты, привычки, заметки и цели сначала перемещаются в корзину.

Чтобы вернуть запись:

1. Откройте **«Данные и резервные копии»**.
2. Найдите раздел **«Корзина»**.
3. Нажмите **«Вернуть»**.

Кнопка **«Очистить»** удаляет содержимое корзины без возможности
восстановления.

## 11. Резервная копия

1. Откройте **«Данные и резервные копии»**.
2. В блоке **«Экспорт JSON»** нажмите **«Скачать копию»**.
3. Сохраните файл в надёжном месте.

Полная копия содержит основные данные, историю времени, корзину и историю
импортов.

Для восстановления выберите этот JSON-файл. FlowTrack покажет предварительную
сводку и предупредит, что текущие данные будут заменены. Перед заменой
приложение автоматически скачает ещё одну копию текущего состояния.

## 12. Планирование с ChatGPT

### Рекомендуемый порядок

1. В окне данных нажмите **«Скачать контекст»**.
2. Прикрепите файл к диалогу с ChatGPT.
3. Опишите цель, сроки, ограничения и желаемую нагрузку.
4. Попросите вернуть план в формате `flowtrack-plan`.
5. Сохраните ответ как файл `.json`.
6. Выберите его в FlowTrack.
7. Проверьте предварительный просмотр и нажмите **«Добавить план»**.

Пример запроса:

> Проанализируй мой контекст FlowTrack и составь реалистичный план. Верни только
> валидный JSON формата `flowtrack-plan`, `schemaVersion: 1`. Используй уникальные
> ASCII-значения `ref`, даты в формате `YYYY-MM-DD`, не изменяй существующие
> записи и не добавляй пояснения вне JSON.

### Минимальный пример плана

```json
{
  "format": "flowtrack-plan",
  "schemaVersion": 1,
  "title": "Подготовка к экзамену",
  "data": {
    "projects": [
      {
        "ref": "exam-prep",
        "title": "Подготовка к экзамену",
        "description": "Закрыть все темы без перегрузки",
        "color": "#7c3aed"
      }
    ],
    "columns": [
      {
        "ref": "exam-todo",
        "projectRef": "exam-prep",
        "title": "К выполнению",
        "order": 0
      }
    ],
    "tasks": [
      {
        "ref": "exam-topic-1",
        "title": "Повторить первую тему",
        "projectRef": "exam-prep",
        "columnRef": "exam-todo",
        "status": "todo",
        "priority": "high",
        "dueDate": "2026-08-01",
        "estimatedMinutes": 45,
        "recurrence": "none",
        "tags": ["экзамен"]
      }
    ],
    "habits": [],
    "notes": [],
    "goals": []
  }
}
```

`flowtrack-plan` не стирает текущие данные. Перед добавлением сервер проверяет
ссылки между объектами, показывает количество записей и пропускает совпадения.
Импорт можно отменить в разделе **«Последние импорты»**.

## 13. Администрирование

Раздел доступен только владельцу:

- на компьютере — через боковое меню;
- на телефоне — через окно профиля;
- напрямую — по адресу `/admin`.

В панели отображаются пользователи, даты регистрации и активности, а также
количество проектов, задач, привычек, заметок и целей. Содержимое личных записей
не показывается.

## 14. Если что-то не работает

### Долгая загрузка

Через 15 секунд FlowTrack остановит зависший запрос и покажет ошибку. Проверьте
интернет и нажмите **«Повторить»**.

### Сессия завершилась

Откройте главную страницу и снова войдите через ChatGPT. Создавать второй
FlowTrack-аккаунт с тем же email не требуется.

### Ошибка импорта JSON

Проверьте:

- расширение `.json`;
- размер до 15 МБ;
- поле `format`;
- поддерживаемую версию схемы;
- даты `YYYY-MM-DD`;
- время `HH:MM`;
- уникальные `ref`;
- существование всех `projectRef` и `columnRef`;
- корректность числовых значений.

### Нет доступа в админку

Обычный пользователь должен видеть сообщение о закрытом разделе. Если вы
владелец, войдите тем аккаунтом ChatGPT, email которого назначен владельцем
сайта.
